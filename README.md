# amvox-dash-faturamento

Dashboard TV de Faturamento & Logistica (AMVOX).

- `web/` painel (TV + 4 telas de detalhe)
- `etl/` carga do Protheus para o cache Supabase
- `sql/` queries de descoberta e extracao
- `db/migrations/` DDL do cache

Dados: Supabase (login obrigatorio). Nenhuma credencial neste repositorio.
